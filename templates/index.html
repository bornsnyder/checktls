checktls

Checks whether a domain's mail server (MX) root CA is accepted by Mimecast.

Enter a domain. We resolve its MX records, connect to each mail server over TLS, and compare the root CA against Mimecast's supported-certificate list.

TLS BATCH CHECK

Upload a CSV export (data starts at line 4, domain in the second column). A leading @ is stripped automatically. Each row becomes an expandable result: green = passed, yellow = partial match, red = failed.
